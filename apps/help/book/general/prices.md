# Цены

Для кандидатов создание резюме, тестирование и общение бесплатны.

## Для работодателей

| Действие | Стоимость | Когда начисляется |
| --- | --- | --- |
| Первая публикация вакансии | 398 ₽ | При публикации |
| Приглашение кандидату | 196 ₽ всего | 49 ₽ при отправке, ещё 147 ₽ при принятии |
| Просрочка обязательного действия | 398 ₽ | При истечении рабочего срока |
| Некачественная обратная связь | 398 ₽ | Только после ручного решения поддержки |

Отказ кандидата до принятия не вызывает доплату 147 ₽. Повтор одного и того же
события не создаёт повторное начисление. Старые приглашения сохраняют тариф,
который действовал при отправке.

Для ИИ действует дневная норма 10 ₽: в расходы попадает превышение нормы
по фактическому использованию. Сутки считаются по московскому времени;
курс для учёта — 100 ₽ за доллар. Это учёт расходов сервиса, а не рыночный курс.

Начисления и полный тариф видны в [статистике](../employer/statistics.md).
По спорному начислению напишите в [поддержку Comit](support.md).
