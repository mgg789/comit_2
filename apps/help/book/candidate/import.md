# Загрузить готовое резюме

PDF или фотография помогут заполнить первый экран формы.

В редакторе найдите блок «Начните с готового резюме». Сначала разрешите обработку файла, затем нажмите на область загрузки или перетащите в неё файл.

Поддерживаются PDF, PNG, JPG и WebP до 5 МБ; PDF — до 10 страниц. Для фотографии нужен чёткий текст без бликов. Исходный файл удаляется после распознавания.

Результат — предложение для заполнения, а не подтверждённые сведения. Проверьте распознанный текст и поля. Ваши уже введённые данные сохраняются; перед публикацией можно всё исправить.
