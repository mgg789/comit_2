# Указать навыки и уровни

Выбирайте домены, стеки и личные навыки из каталога.

Для каждого навыка выберите понятный уровень: Intern, Junior, Middle и следующие уровни. Произвольный стек не добавляется: дополнительные сведения можно написать в описании.

Заявленный вами уровень и подтверждённый тестом результат различаются. На плашке навыка нажмите «Подтвердить» или «Улучшить», если доступна проверка. «Пока нет теста» означает, что для этого навыка проверка ещё недоступна.
