# Ассеты кабинета кандидата

Оригинальные экспорты [Figma, раздел «Кандидат»](https://www.figma.com/design/gPFLCJKXEoRwRP3YLyMsX4/Untitled?node-id=444-15763).

- `f4e60.png`, `44a44.png`: фон резюме, узлы 444:16346–444:16348.
- `bb5d7.png`: фон предложений, узел 444:16625.
- `af3af.png`: фон статистики, узлы 444:15772–444:15773.
- `759f5.png`: декоративная иллюстрация статистики, узел 444:16064.
- `abd1b.svg`, `0f423.svg`: иконки резюме и предложений, узлы 444:16352 и 444:16636.

Общие шрифты, бренд и остальные иконки берутся из `@comit/ui-kit`.
Фотографии кандидата, аватары и логотипы компаний из примеров макета не добавлены: это данные конкретных пользователей, для них используются инициалы до появления соответствующего публичного контракта.
