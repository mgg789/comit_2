# MVP-скоуп и план на неделю разработки (5–11 октября)

> Окно разработки ~6–7 дней (по VK-данным; дату промежуточной сдачи уточнить). Приоритет — по весам критериев: подбор (35%) + тестирование/валидация (25%) = 60%. Всё остальное — после того, как эти два контура демо-готовы.

## Скоуп MVP (должно быть к дедлайну)

### Обязательный контур (60% оценки)
- [ ] Регистрация email + подтверждение, роли, 152-ФЗ согласия
- [ ] Кандидат: профиль, опрос специализации, выбор заявленного грейда
- [ ] Testing engine: blueprint'ы, варианты, грейд-тест → категория (понижение/повышение + cooldown)
- [ ] Рейтинг подтверждённых полей (ledger + очки на профиле)
- [ ] Комбайн: strict filter → score → top-k → реранкер → Selection с объяснением
- [ ] Тиндер у работодателя: карточки с обоснованием попадания, лайк/скип, коррекция вектора вакансии
- [ ] Приглашения: ЗП от–до обязательна, статусы обеих сторон, контакты только после принятия
- [ ] ФСП-профиль (мок-структура) + корректная обработка отсутствия
- [ ] Добор/переотбор: порог изменчивости, правила возврата отклонённых

### Кабинеты (10% UI)
- [ ] Кандидат: профиль/настройки приватности, тесты, история грейда, приглашения
- [ ] Работодатель: компания, вакансии, подборка с объяснимостью, тиндер, приглашения, статусы

### Сдача (документация 6% + питч 10%)
- [ ] Документация: архитектура, механики, валидация + результаты, схема интеграции с ФСП, API (OpenAPI), библиотеки с версиями, инструкция запуска
- [ ] Процедура валидации выполнена и описана (п.1–4 из [[50-matching-engine]] и [[60-testing-engine]])
- [ ] Презентация pptx/pdf + сквозное демо
- [ ] Развёрнутый прототип (наш сервер) + видео-фоллбэк
- [ ] docker-compose воспроизводимо поднимает всё + seed синтетики

### Допфункционал (7%) — брать по остатку, самый дешёвый первым
1. Отклик кандидата на вакансии + публикация вакансий работодателем (у нас вакансии уже есть — отклик дороже)
2. Концепция защиты от фиктивных вакансий + ATS (документ, не код — дёшево)
3. Регулярные короткие задания от работодателей
4. Адаптивная мобильная вёрстка

## План по дням (черновой)

| День | Фокус | Выход |
|---|---|---|
| Пн 5.10 (сегодня) | Скелеты: монорепо, compose, схема БД, auth, OpenAPI | `make up` поднимает всё пустое |
| Вт 6.10 | Кандидат: профиль + опрос + заявленный грейд; blueprint-формат; верификация полей + очки | Кандидат без теста, рейтинг работает |
| Ср 7.10 | Testing engine: генерация вариантов, песочница, грейд-тест → категория | Кандидат получает категорию |
| Чт 8.10 | Комбайн: вектора, скоринг, top-k, объяснимость; вакансии работодателя | Вакансия получает подборку |
| Пт 9.10 | Тиндер + фидбек вектор + приглашения + статусы + правила видимости | Сквозной сценарий работает |
| Сб 10.10 | Пост-отбор (упрощ.): принятие → форма обратной связи; SLA; добор; ФСП-мок; синтетика-генератор | Полное демо-путешествие |
| Вс 11.10 | Валидация + цифры, документация, презентация, деплой, полировка UI | Сдача |

⚠️ План агрессивный: бэкенд-движки (ср–чт) — критический путь. Если застреваем — режем пост-отбор и адаптив, НЕ режем тестирование и объяснимость.

## Демо-скрипт (сквозной, по ТЗ 3.3)

1. Регистрация соискателя → опрос → заявленный грейд → тест (показать генерацию варианта!) → категория.
2. Показать вторым кандидатом сценарий «без истории ФСП» и третьим «с ФСП-бейджами».
3. Работодатель: описание потребности → вакансия → подборка с объяснением «почему эти».
4. Тиндер: лайк/скип → показ коррекции вектора (в dev-инструментах или на слайде).
5. Приглашение с ЗП → кандидат видит → принимает → контакты раскрылись → оффер/отказ + обратная связь.
6. Отдельно: слайды механики тестирования (анти-утечка) и механики подбора (пайплайн + валидационные цифры).

## Синтетические данные (готовых датасетов нет — ТЗ)

- Генератор: 200+ кандидатов (профили по специализациям × грейдам, часть с ФСП-достижениями, часть без), 10 вакансий с эталонной разметкой релевантности, компании, результаты тестов.
- Два работодателя-агента с фиксированными предпочтениями для демонстрации сходимости тиндер-лупа.
- Реалистичные описания вакансий (стек, задачи команды) — руками, 10 штук.
