# Еженедельная практика

Кандидат открывает «Задание недели» в резюме: три параметризованных вопроса по данным и логике, одна отправка за календарную неделю UTC. Два верных ответа из трёх дают отметку активности. Новый набор доступен каждый понедельник 00:00 UTC без ручного запуска или планировщика; интерфейс показывает границу в локальном времени браузера.

Это практика платформы, не подтверждение грейда и не задания работодателей. Текущий банк не рассчитан на защиту от распространения ответов. Повторная отправка возвращает сохранённый результат; создание нескольких аккаунтов требует отдельной защиты и сейчас не предотвращается.

`GET /candidate/weekly-challenge`, `POST /candidate/weekly-challenge/start`, `POST /candidate/weekly-challenge/submit` требуют сессию кандидата, а запись — допустимый Origin. Ответ содержит только вопросы/варианты и итоговое число верных ответов. Ключи ответов остаются на сервере. `candidate_weekly_challenges` имеет уникальную пару кандидат/неделя; запись результата, evidence и проекция выполняются одной транзакцией с блокировкой профиля. Отозванное согласие на обработку запрещает участие.

Сервер создаёт `external:weekly_challenge:current`, срок — следующий понедельник. Повторные прохождения не накапливают бонус. В matching применяется только среди близких по основному score кандидатов, без изменения категории и базового скоринга; режим активации и границы описаны в [matching.md](matching.md). В shadow-режиме отметка сохраняется и измеряется, порядок не меняется. Это явно ограниченный сигнал активности, а не доказательство профессионального уровня.
