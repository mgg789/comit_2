# Тестовые документы Comit для хакатона

Редакция: 7 октября 2026 года. Статус: тестовая EULA в рамках хакатона,
не комплект документов для публичного промышленного запуска.

Реквизиты оператора (ФИО/наименование, адрес), адрес платформы, страна основной
БД, перечень обработчиков и сроки хранения будут добавлены позднее.
Для связи: **support@droidje.com**, Telegram **[@droidje](https://t.me/droidje)**.
Для обращений о персональных данных предпочтителен email: не отправляйте
документы, коды входа и другие конфиденциальные сведения в публичные чаты.

- [Политика конфиденциальности](privacy-policy.md) описывает все контуры обработки.
- [Согласие на обработку данных](processing-consent.md) отдельно от политики:
  аккаунт (`account-v1`) и собственный профиль (`profile-v1`).
- [Отдельное согласие на показ профиля](pool-consent.md): выбор pool в profile-v1.
- [Добровольное согласие на обучение ИИ](training-consent.md): `training-v1`.

Документы не заменяют друг друга. Ознакомление с политикой само по себе не
означает принятие согласия. Регистрация не публикует профиль. Отказ от обучения
не мешает регистрации, участию в подборе и общению с работодателем.
Тестовый статус не отменяет требований законодательства к реальным данным.
До заполнения реквизитов и проверки размещения/обработчиков использовать
синтетические профили; существующие записи не получают разрешение на обучение
автоматически.

Перед публичным запуском оператору необходимо утвердить реквизиты, правовые
основания, сроки и порядок уничтожения/резервных копий, договоры с обработчиками,
локализацию и возможную трансграничную передачу, обязанности по уведомлению
Роскомнадзора, а также механизм сохранения точной редакции предъявленного текста.
Удаление аккаунта и всех копий данных через самостоятельный API пока не реализовано;
отзыв согласий и прекращение использования в подборе/обучении — реализованы.

Технический контракт: [профиль](../candidate-profile.md),
[аккаунты](../auth.md), [обучение](../real-card-learning.md), [чаты](../chat.md).
Правовые ориентиры: [152-ФЗ, статья 9](https://www.consultant.ru/document/cons_doc_LAW_61801/6c94959bc017ac80140621762d2ac59f6006b08c/),
[структура политики по рекомендациям Роскомнадзора](https://www.consultant.ru/document/cons_doc_LAW_221615/).
