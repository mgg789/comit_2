# Глоссарий

Термины, которые встречаются в коде, API и документации. Ссылки ведут к подробному
описанию.

| Термин | Значение |
|---|---|
| **Обратная механика найма** | Кандидат не откликается: работодатель находит его в подборке или витрине и сам отправляет приглашение с зарплатой «от–до». |
| **api-core** | Сервис `apps/api` на Fastify — единственный публичный API и транзакционное ядро ([services.md](services.md)). |
| **Комбайн** | Конвейер matching-engine: строгий фильтр → гибридный скоринг → main top-k → реранк ([matching.md](matching.md)). |
| **Строгий фильтр** | Жёсткие условия вакансии: класс специализации, зарплатные границы, форматы работы, города, переезд, исключения; кандидат вне фильтра в main top-k не попадает. |
| **Гибридный скоринг** | Объяснимая сумма признаков и семантической близости эмбеддингов; каждая карточка несёт факторы попадания. |
| **Harrier** | Модель эмбеддингов, которую matching-engine держит в локальном кэше (`harrier_cache`, `HF_HOME`); без подготовленного snapshot `/ready` возвращает 503 ([deploy.md](deploy.md)). |
| **Main top-k** | Основная подборка лучших кандидатов вакансии после скоринга. |
| **R₀ / реранкер** | Линейная модель, переупорядочивающая main top-k. Работает в режиме **sort-only**: меняет порядок, не отсекая хвост ([rerank-activation.md](rerank-activation.md)). |
| **main_fallback** | Режим без активного R₀: порядок main top-k сохраняется. |
| **Golden** | Отложенная выборка для честной финальной оценки; на ней не подбирают параметры. |
| **Quality gate / activation gate** | Формальные условия качества разметки и численного выигрыша модели, после которых модель может стать активной через обычный promote. |
| **Recommended / reserve** | Две части подборки: рекомендованные и резерв ([api.md](api.md)). |
| **Лента (feed)** | Свайп-просмотр кандидатов вакансии работодателем: показы (impressions), решения (decisions), сессии и добор (refill) ([feed-refill.md](feed-refill.md)). |
| **Preference-модель** | Vacancy-local поправка к порядку, обучаемая на реакциях работодателя; переставляет только ещё не показанный суффикс ленты ([preference-learning.md](preference-learning.md)). |
| **Гипотезы / research-показы** | Ограниченные показы для проверки гипотез о предпочтениях работодателя, 2 карточки на 18 обычных доставок ([hypothesis-learning.md](hypothesis-learning.md)). |
| **FSP boost** | Дозированная прибавка к скорингу за подтверждённый разряд ФСП и недельную активность; режимы `MATCHING_PROMOTION_MODE` = `off`/`shadow`/`active`, максимум 0.02 ([matching.md](matching.md)). |
| **Saved / visited** | Сохранённые лайком и просмотренные работодателем кандидаты вакансии. |
| **Витрина (showcase)** | Публичный и работодательский поиск по кандидатам и вакансиям, согласившимся на показ ([public-showcase.md](public-showcase.md), [candidate-showcase.md](candidate-showcase.md)). |
| **Проекция профиля** | Асинхронная передача снимка профиля кандидата из api-core в matching-engine через outbox и `candidate-profile-worker` ([candidate-profile.md](candidate-profile.md)). |
| **Outbox** | Таблица событий, которая пишется в той же транзакции, что и изменение данных; worker доставляет события с повторами (at-least-once). |
| **Lease** | Временная аренда задания worker-ом; истёкшая аренда позволяет другому worker продолжить, старая не может перезаписать новое состояние. |
| **CAS / `expected_revision`** | Оптимистическая блокировка: изменение принимается только для ожидаемой ревизии, иначе 409. |
| **`idempotency_key`** | UUID повторяемой команды: повтор возвращает прежний результат без дублей. |
| **Согласия** | Раздельные согласия кандидата: регистрация аккаунта, обработка резюме, показ в пуле подбора (pool) и необязательное обучение моделей (training) ([legal/README.md](legal/README.md)). |
| **Evidence** | Подтверждающая запись о навыке или факте профиля с источником; `self_reported` — заявлено кандидатом, `grade:trusted` — подтверждено тестом. |
| **Blueprint** | Параметризованный шаблон задания testing-engine; из него генерируются варианты ([testing-design.md](testing-design.md)). |
| **Адаптивный тест** | Тест, который начинает с уровня L2 и выбирает следующие задания по ответам до решения с вероятностью 0.70, максимум 30 заданий ([testing-engine.md](testing-engine.md)). |
| **Supervision** | Агрегаты наблюдения за попыткой (время в кадре, потеря фокуса, несколько лиц, статус камеры); вспомогательный сигнал, решение о добросовестности остаётся за человеком. |
| **Trusted publisher** | Компонент testing-engine, отправляющий итог попытки в `POST /internal/testing/session-result` api-core. |
| **code-judge** | Изолированный сервис проверки кода на отдельной VM, Docker-контейнер на каждый testcase ([services.md](services.md#code-judge-servicescode-judge)). |
| **Недельное задание** | Практическое задание недели для кандидата ([weekly-challenges.md](weekly-challenges.md)). |
| **ФСП** | Федерация спортивного программирования; разряды и история участника подтверждают навыки. В проекте используется мок-реестр integration-engine и демо-привязка профиля ([fsp-link.md](fsp-link.md)). |
| **DeepSeek, Jev** | Модели-провайдеры: DeepSeek — основной провайдер агентов; Jev (SystemOne API `kev-latest`) — подсказки и действия агента, деривация требований вакансии и, если настроен, проверка развёрнутых ответов теста (иначе DeepSeek). Историческое имя Jev-провайдера — Laya: оно сохранилось в идентификаторах кода (`laya_not_configured`, `laya-requirements-v2`, модель `laya-multilingual-mlx`) и в датированных логах пилотов ([agents.md](agents.md), [testing-engine.md](testing-engine.md)). |
| **Глобальный агент организации** | Один AI-чат работодателя на аккаунт с памятью, документами, бюджетом и фоновыми поручениями ([agents.md](agents.md)). |
| **Офлайн-дублёр** | Поручение агенту отвечать за работодателя, пока тот офлайн; возвращение владельца прекращает отправку. |
| **QGramm** | Мессенджер, на котором построены чаты найма; доступен api-core через внутреннюю сеть `chat-private` ([chat.md](chat.md)). |
| **Системный чат** | Канал платформы в обоих кабинетах: уведомления и переписка со службой поддержки ([system-inbox.md](system-inbox.md)). |
| **Консоль поддержки** | Приложение `/support/` для оператора; включается переменными `SUPPORT_EMAIL` и `SUPPORT_ACCESS_KEY` ([support-console.md](support-console.md)). |
| **`expense-v1`** | Версия политики начислений работодателю: публикация вакансии, приглашение, просроченный дедлайн, превышение дневного лимита ИИ ([api.md](api.md)). |
| **SSE** | Server-Sent Events: потоки `…/recruitment-events/stream` для событий найма в реальном времени. |
