# Главная страница COMIT

`apps/welcome` реализует публичную входную страницу по Figma `170:15064`: логотип, три перехода, исходные фоновые изображения и SVG. Шрифты Inter SemiBold, Murs Gothic и Moon Walk скопированы из существующих ресурсов employer; палитра импортируется из `@comit/ui-kit/tokens.css`. Размеры SVG и их геометрия сохранены. На узких экранах карточки складываются в две строки с полноширинной кнопкой.

Переходы ведут в существующие приложения: `/candidate/` и `/employer/`. В режиме Vite используются реальные порты соседних приложений 5173 и 5174 на текущем хосте и протоколе главной страницы (например, `http://127.0.0.1:5173/candidate/` и `http://127.0.0.1:5174/employer/`), чтобы сохранить хост авторизационных cookies. Для другого локального хоста или стенда предусмотрены `VITE_CANDIDATE_URL` и `VITE_EMPLOYER_URL` (полные базовые URL приложения). Главная запускается на порту 5176.

Кнопка «К витрине COMIT» ведёт на существующий маршрут employer `#/showcase`. Этот маршрут требует авторизации работодателя: отдельная публичная витрина вакансий и резюме и её API сейчас отсутствуют. Главная не загружает профили и не показывает вымышленные записи. Публичная витрина потребует отдельного контракта с правилами видимости; текущая страница сохраняет существующий доступ через employer.

Статическая проверка: `pnpm --filter @comit/web-welcome typecheck`. Браузерная проверка и тесты не запускались по прямому ограничению задачи; точность в реальном браузере пока не подтверждена.
