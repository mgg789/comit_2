# Резюме кандидата: prerelease-изменения

## Зарплата

Редактор собирает только минимальную зарплату. `salary.to_rub: null` в source profile, intake, pool, matching card и публичной витрине означает отсутствие потолка. Существующие конечные интервалы читаются совместимо; при сохранении через новый редактор остаётся минимум без потолка. Вакансии, приглашения и фильтры поиска сохраняют обязательные конечные вилки.

Strict gate допускает кандидата, когда максимум вакансии не ниже его минимума. Для legacy конечного интервала сохраняется пересечение. При расчёте числовых признаков реранкера открытый потолок ограничивается максимумом текущей вакансии (не ниже минимума кандидата), чтобы не использовать infinity, искусственные огромные зарплаты или менять веса скоринга. Признаки остаются конечными; их имена и порядок не меняются. OpenAPI перегенерирован из моделей.

## Импорт и достижения

Загрузка PDF/фотографии — доступная кнопка внутри высокой drop zone. До явного согласия на обработку drop zone затемнена, выбор файла отключён, drag/drop ничего не загружает. После распознавания предложения заполняют только пустые поля; пользователь проверяет их перед сохранением. Демо для печати и OCR: [`../demo/resume-alexey-sokolov.pdf`](../demo/resume-alexey-sokolov.pdf).

В достижении «Организация» отображается как «Мероприятие»; wire-field `organization` сохранён совместимо. Фото/PDF прикрепляются отдельно от ссылки через существующие `POST /api/candidate/profile/verification-documents` и owner-scoped list/download. Новое достижение получает стабильный UUID от сервера; временный ID редактора не передаётся API. Выбранный файл загружается после сохранения профиля с возвращённым сервером ID. Файл в редакторе не сохраняется между перезагрузками. При неудаче файл можно загрузить снова в сохранённом достижении; профиль сохраняется, ошибка явно показана.

Документы шифруются существующим AES-256-GCM хранилищем, имеют статус pending и сами по себе не подтверждают достижение. Это приватные документы кандидата; публичная витрина их не раскрывает.

## Документы и чекбоксы

Канонические Markdown `docs/legal` включены в Docker build до Vite. Их чтение не требует сессии; кандидат и работодатель используют общий безопасный рендерер заголовков, таблиц и ссылок. Все чекбоксы используют общий Checkbox/его CSS, включая импорт и настройки работодателя.
