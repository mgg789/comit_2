> Неймспейс `hypothesis-validation-v1`, evaluation-only: живая политика

> Sealed отчёт: `tests/artifacts/reranker/hypothesis-validation-v1/report.json`

## Три инструмента

1. **Распространённость.** Настоящий `comparable_pairs()` на запечатанных пулах:
   hard-бенчмарк v7 (84 кандидата) и v9-корпус (420). Плюс офлайн-сценарии
   релаксации (контраст 0.15→0.10, nuisance 0.15→0.30, utility 0.35→0.60).

   | Пул | live | contrast 0.10 | +nuisance 0.30 | relaxed all |
   |---|---:|---:|---:|---:|
   | hard-84 | **0** | 5 | 5 | 5 |
   | v9-420 | **3** (H2) | 19 | 35 | 36 |

   Связывающее ограничение — `MIN_CONTRAST=0.15`; nuisance — второе; utility
   почти не влияет. H5/H6/H10 на sealed-пулах структурно неизмеримы (нет
   narrative_facts/category/semantic_space_id в снапшотах) — зафиксировано
   в манифесте.

2. **Воронка решаемости.** Пара становится решающей, только если работодатель
   лайкнул одну сторону и дизлайкнул другую. При явном допущении q=0.25 (допущение
   записано в манифесте — телеметрии реакций нет) один замороженный батч из
   20 решающих пар на семейство требует **~1600 проходов пула** в live-калибровке
   и ~134 в релаксированной. На масштабе хакатона вердикты H1–H10 недостижимы.

3. **Мощность вердикта.** Monte Carlo (2000 seeds × 20 решающих пар) через
   настоящий `summarize()` с Bonferroni-Wilson:

   | Истинный p (support) | supported | not_supported | unclear |
   |---|---:|---:|---:|
   | 0.50 | 0.25 % | 0.20 % | 99.6 % |
   | 0.65 | 4.95 % | 0 | 95.1 % |
   | 0.80 | 40.6 % | 0 | 59.4 % |
   | 0.95 | **98.75 %** | 0 | 1.25 % |

   Замороженный батч из 20 пар надёжно отделяет только очень сильные эффекты
   (p ≥ 0.95); ложные вердикты ограничены per-side бюджетом Bonferroni (0.0025)
   — коррекция работает как спроектирована.

## Выводы для оператора

- Слой гипотез в текущей калибровке — **длинный горизонт**: research-карты на
  реальных пулах почти не порождаются (0–3 за полный проход), вердикты — только
  для очень сильных эффектов после сотен проходов пула. Для демо это значит:
  статус-эндпоинт честно показывает «collecting», обещать вердикты нельзя.
- **Менять live-политику сейчас нельзя дёшево**: смена policy_hash инвалидирует
  работающие hypothesis-контексты. Если когда-то решено оживить слой — это
  policy-v2 (contrast ≈0.10, nuisance ≈0.30, возможно меньший frozen-батч с
  пересчитанной α) отдельным решением с миграционной ценой; абляционная таблица
  выше — готовая доказательная база.
- H9 (adjacency taxonomy) остаётся выключенной: при текущей
  распространённости включение десятого семейства ничего не меняет; возвращаться
  к нему только после policy-v2.

## Честные границы

q=0.25 — явное допущение, не измерение. Пулы без narrative_facts ограничивают
проверку семействами H1–H4/H7/H8. Monte-Carlo — односемейный (H2), статистика
summarize одинакова для всех семейств кроме выключенной H9. История версий
чистая: v1 сразу запечатана с отчётом.
