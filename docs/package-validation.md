## Реальный интерфейс и данные

В изолированном браузерном стенде с синтетической учётной записью пройдены еженедельное задание и привязка demo FSP; результат сохраняется после перезагрузки. На ширинах 1280 и 390 px проверены форма импорта, согласие и отсутствие горизонтального скролла. Транспорт PDF проверен API acceptance; отдельный браузерный проход preview/apply ещё завершается.

Импортированы 240 вымышленных резюме и 48 вакансий, повторный импорт идемпотентен, письма не отправлялись. Проверенный объём фактической публикации через Harrier/штатные workers и текущие очереди указан в [demo-data.md](demo-data.md) и [`acceptance.json`](../data/demo/acceptance.json). Число исходников не равно числу готовых карточек.

Локальный Jev вернул некорректное равномерное заполнение, поэтому подтверждены транспорт, кэш и безопасный отказ от сомнительного ответа, но не качество модели. Пользователь подтвердил, что production Jev будет другим; основной провайдер сохранён без DeepSeek fallback. Подробности: [vacancy-suggestions.md](vacancy-suggestions.md).

## Границы доказательств

- Precision/MRR и остальные измерения используют синтетические teacher labels. Четыре семейства quarantined после quality gate; отчёт не является оценкой реального найма: [matching.md](matching.md).
- FSP demo явно маркирован. Настоящий внешний реестр организатора не подключён.
- Promotion включён только в явном dev-профиле; production default `shadow`. Базовые оценки, strict filtering и shortlist не изменены; новые перестановки ограничены разницей 0,02 базового score.
- Полный remote CI и обязательный compose smoke для этого пакета ещё не выполнены. До зелёного smoke слияние в dev запрещено.
- Production не изменён; реальные аккаунты, физическая камера и production-модель Jev этим пакетом не проверялись.
