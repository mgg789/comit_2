# Ручной режим при недоступных моделях

`AGENTS_MODE=manual` отключает агентный чат и автоматическое определение
требований без сетевых запросов. В обычном режиме сервис проверяет наличие
DeepSeek-токена и доступность его официального API, отдельно — доступность
локального Jev. Проверки ограничены двумя секундами и кешируются на 30 секунд.

`GET /employer/agents/capabilities` сообщает `agent`, `enrichment` и
`manual_editing=true`. Недоступная операция не ставится в очередь и возвращает
`agent_disabled_manual_available`; запросы уже находящиеся в очереди также
проверяются воркером. Данные сохраняются для ручного редактирования.
Ручная форма использует локальный matching-реестр, вводит классы и уровни
напрямую и проходит прежние approve → summary → Create. При отказе провайдера
система не подставляет сгенерированные ответы и не публикует вакансию автоматически —
решение остаётся за работодателем.

Доступность HTTP endpoint проверяется отдельно от наличия конкретной модели: ошибка
реального вывода отображается как статус задания, и ручной путь остаётся доступен.
