# ADDITIONAL — сверх обязательного ядра

Обязательные требования не дублируются здесь: [CORE](core.md), [ТЗ §6.6](../context/tz/00-fsp-tz-2026.md).

| Возможность | Реализация | Граница подтверждённого результата |
|---|---|---|
| Недельные мини-задания | [weekly-challenges.md](weekly-challenges.md), 3 параметризованных вопроса, серверный итог, один бонус до следующего понедельника | Практика платформы; редактор заданий работодателя пока не реализован. Не подтверждает грейд, не защищает от нескольких аккаунтов |
| PDF/фото → анкета | [resume-import.md](resume-import.md), pypdf/Tesseract, предварительный просмотр, ручная правка | OCR может ошибаться. Не выдумывает уровни навыков и не подтверждает факты |
| Автоподсказки требований Jev | [vacancy-suggestions.md](vacancy-suggestions.md), durable jobs и cache, защита ручных изменений | Локальная модель даёт слабые результаты; будущий production-Jev нужно проверить отдельно. Нет подмены выдуманными значениями |
| Демо-каталог | [demo-data.md](demo-data.md): 240 кандидатов, 48 вакансий, 16 компаний | Вымышленные, помеченные данные; без писем и поддельной верификации. Источники не равны готовым embedding/публичным карточкам |
| Чаты и уведомления | Диалоги найма и системный Comit inbox, unread counters | Реальные сессии/роли; внешний QGramm проверяется отдельным acceptance, не unit-заглушкой |
| Сроки найма и обратная связь | Рабочие дни, напоминания, отказ с ОС, агрегация рекомендаций | Штраф за качество ОС определяется поддержкой, не автоматической «оценкой мусора» |
| Расходы | Журнал размещений, инвайтов, использования ИИ сверх нормы и неустоек | Учёт операций не является платёжным шлюзом |
| Защита недобросовестного найма | Сроки, обязательная обратная связь, исторические действия | Полная модерация работодателей/антифрод пока не реализованы |
| ATS и реальный ФСП ID/Keycloak | Архитектурные точки интеграции в context и docs | Не заявляются как работающие внешние интеграции |
| Мобильная версия | Адаптивные формы и основной UI | Физические mobile-устройства и захват экрана на них требуют отдельной проверки |
