# Стеклянные поверхности UI

Общий `Backdrop` из `packages/ui-kit/src/design.tsx` включает эксперимент стекла во всех приложениях. `.glass`, фон `.glass-surface::before`, карточки предложения кандидата и теста, tooltip и swipe используют общие токены. Текст и контролы не фильтруются. Активная вкладка в эксперименте сохраняет новое стекло со светлыми текстом/иконкой и голубой рамкой (classic сохраняет прежний светлый фон); composer сохраняет плотную тёмную подложку, чтобы фон страницы не снижал контраст текста и кнопки вложения. Эксперимент и его fallback не переопределяют эти две поверхности.

Chromium с поддержкой SVG в `backdrop-filter` использует статическое преломление фона. Safari, Firefox и браузеры iOS используют матовое стекло. Без поддержки backdrop-filter фон становится непрозрачнее для читаемости. Определение возможностей консервативное: CSS.supports само по себе не доказывает поддержку SVG-преломления в WebKit.

Для отката добавьте `?glass=classic` перед `#` в адресе любого приложения (например `/candidate/?glass=classic#/profile`). Это возвращает исходные стили, не меняя код и данные. Общий селектор — `data-comit-glass` на корневом HTML-элементе; режимы: `classic`, `frosted`, `refractive`.

Один SVG-фильтр обслуживает все поверхности. Canvas, WebGL, requestAnimationFrame и observers для каждого элемента не создаются. Остальные режимы не используют SVG-фильтр. Фильтр не подгружает внешние ресурсы.

Визуальный ориентир — GlassSurface React Bits. Его исходный код не импортирован: upstream [LICENSE.md](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) содержит MIT + Commons Clause; реализация Comit расширяет собственный SVG-фильтр и использует существующие дизайн-токены. Новых зависимостей нет.

Публичная витрина использует фиксированный каталог направлений из `SPECIALIZATIONS`. Произвольный поиск по названию оставлен только для вакансий. Сортировка компактная и при недостаточной ширине переносится на отдельную строку. Зарплата кандидата с `to_rub: null` отображается как «от …к ₽».

Проверки: `pnpm --filter @comit/ui-kit test`, `pnpm --filter @comit/ui-kit typecheck`, `pnpm --filter @comit/web-welcome typecheck`. Реальное преломление и читаемость необходимо отдельно проверять браузером.

Модальные окна, меню аккаунта/уведомлений, панели инструментов ассистента, контекстные меню и tooltip сохраняют прежние подложки; вложенные кнопки продолжают использовать новое стекло. Красные destructive actions исключены из глобального фонового переопределения. Чекбокс согласия при входе центрируется по всей высоте многострочного текста.
