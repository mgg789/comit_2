## Демо-резюме

[resume-alexey-sokolov.pdf](resume-alexey-sokolov.pdf) — одностраничное резюме с вымышленными данными. Можно загрузить PDF в редактор резюме или распечатать и сфотографировать для проверки OCR. Имя, контакты, компании и достижения предназначены только для демонстрации.

После распознавания проверьте предложения перед сохранением: импорт заполняет только пустые поля и не подтверждает навыки или достижения.
